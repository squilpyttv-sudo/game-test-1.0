1. Token palette — css/tokens.css

Every custom property declared on :root, resolved to its actual computed value in this page.

2. Prop families × tiers

Iterates Iso.propMap (item id → family/tier) and draws each with Iso.drawFamily() at rotation 0, against a neutral checkerboard so silhouettes read clearly. Labelled with item id, family, tier, and the shop name from Data.shopItems.

3. Prop rotations (rot 0–3)

One row per family (highest tier shown), all four rotations, so it's obvious which families' art actually changes when rotated in the editor.

4. Backdrops, rooms & day/night

The 6 locations from Data.locations, each rendered as a full room via Iso.renderRoom() (drawBackdrop/floor/walls aren't individually exported) at three points across the day-night cycle: day (0), sunset (0.5), night (1). Also shown: the travel transition (van + road) and a packed moving-box.

5. Misc Iso renderers

Anything else window.Game.Iso exports that draws pixels: shop icon renderer, packed box, travel transition.

6. CSS component inventory

Live examples using the real game stylesheets and classes, grouped by source file. This is a representative sample of every component family named in the brief (buttons, panels, meters, badges, cards, phone tiles, toasts, screen headers, nav buttons, banners) — not literally every one of the ~600 selectors across 8 stylesheets.
